# 状态机

基础状态对象与嵌套行为并非过度设计：状态有进入/退出、更新及输入职责时值得保留。简单流程使用 `CoreStateMachine`，行为对象使用 `BaseState` / `BaseStateMachine`，不要强制所有流程都注册为全局状态机。

运行语义、可执行示例、兼容性变化及验证命令统一维护在 [英文接口说明](state_machine_system.md)，避免两份文档描述不同接口。

本次移除了基础状态隐式读取 `CoreSystem.logger` 的依赖；修复重复准备、嵌套重复进入、转换重入、暂停误清活跃状态、弱引用所有权和回调期间注销丢失清理的问题。状态机管理器仍作为可选 Godot 驱动器保留。无类型变量包和旧转换别名为兼容保留，新代码优先显式类型化上下文。

C# 行为状态机对齐生命周期、驱动、暂停、转换顺序、历史与实例所有权，嵌套使用组合；不会为接口名称一致复制原版的全局注册或 Variant 变量包。C# 用异常，GDScript 用错误报告及拒绝返回值，两种语言的错误机制并不相同。

注意兼容性变化：运行期间不允许替换注册状态；重复转换不再退出后重新进入；暂停仍保留当前状态的活跃标记；生命周期回调中的注销返回 false 并保留注册；多根状态查询需要指定根 ID；同一次输入导致子状态变化后，不再继续触发该机器的父级输入处理。异步回调取消由使用者负责。

验证记录：Godot 4.7.2 下 61 项状态/计时器独立检查通过，无 CoreSystem 自动加载依赖；真实嵌套场景也通过输入、历史恢复及退出检查。启用原版全部模块的会话仍报告 single_thread.gd 的既有退出泄漏，本次没有修改线程工具。
